# 🎓 Learning Management System (LMS) - Frontend

An interactive, responsive Learning Management System (LMS) frontend built using **React**, **Redux Toolkit**, and **Tailwind CSS**.

---

## ✨ Key Features
- 🔐 **Authentication & Authorization:** User registration, login, profile updates, and role-based access control.
- 📚 **Course Management:** Browse course catalog, view detailed course descriptions, and watch lectures.
- 📊 **Admin Dashboard:** Manage and create courses, upload lectures, and monitor platform metrics.
- 💳 **Checkout Flow:** Payment gateway user interface integration.
- 🎨 **Responsive UI:** Dark theme styling built with Tailwind CSS & DaisyUI.

---

## 🛠️ Tech Stack
- **Core:** React.js, Vite
- **State Management:** Redux Toolkit, React-Redux
- **Routing:** React Router DOM
- **Styling:** Tailwind CSS, DaisyUI
- **Icons & Visuals:** React Icons, Chart.js, React-Chartjs-2
- **Networking:** Axios, React Hot Toast
